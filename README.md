# 花禮卡片排版

花店送花禮時使用的卡片排版工具。選範本、改字、改顏色、調位置,按「列印」直接印在裁好的卡紙上。

整個工具就是一個檔案 `index.html`,沒有要安裝或建置的東西。

## 放到 GitHub Pages

1. 在 GitHub 建一個新的 repository(例如 `flower-cards`)。
2. 把 `index.html` 和這份 `README.md` 上傳到 repository 的最上層。
3. 到 repository 的 **Settings → Pages**。
4. **Source** 選 `Deploy from a branch`,**Branch** 選 `main`,資料夾選 `/ (root)`,按 Save。
5. 等一兩分鐘,頁面上方會出現網址,通常是 `https://你的帳號.github.io/flower-cards/`。

也可以不放 GitHub,直接在電腦上對 `index.html` 點兩下,用 Edge 或 Chrome 開啟,功能都一樣。

## 第一次列印前

1. 在印表機的「列印喜好設定」新增自訂紙張,尺寸和卡片一樣(例如 190 × 257 公釐)。每種尺寸只要設定一次。
2. 在頁面按「列印」,列印視窗跳出來後:
   - 紙張大小選剛剛新增的尺寸
   - 邊界選「無」
   - 縮放選「100%」
   - 取消勾選「頁首及頁尾」
3. 先印「列印校正頁」,用尺量框線到紙邊的距離(應為 10 公釐),再到「怎麼印出來」裡填左右、上下微調。

## 資料存在哪裡

已存的卡片和改過的範本,存在這台電腦的瀏覽器裡(localStorage)。以下情況會不見:

- 清除瀏覽資料或 Cookie
- 換瀏覽器或 Windows 使用者帳號
- 網址改變

內建的 8 個範本寫在程式裡,不會消失。

請偶爾按左側的「匯出備份」,把卡片和範本存成 `.json` 檔。要還原時按「匯入備份」。

## 字型

卡片使用 Windows 內建的「標楷體」。Mac 會改用 BiauKai。

## 新增或修改內建範本

內建範本在 `index.html` 裡的 `BUILTIN` 清單。每個範本是一組文字框,單位是公釐和 pt。
